Methodology

  • Index. Malee ฿/ml ÷ median matched-peer ฿/ml × 100, same retailer and channel, category, juice-% band, size band and pack type. Today's selling price. Multi-buy is shown separately and is not inside the index. Unweighted median. No sales weights.
  • Default set is tier A+B (the three promotion pages, plus Lotus's product pages for prices that are not on the weekly list): n=28, median 101.5. Tier A alone is n=1, median 102.89.
  • Tier C (All Online) is calculated separately: n=8, median 102.47.
  • Calendar. A bar is drawn only when the source prints both a start and an end. Nothing is estimated from the time the page was read.
